## 🧠 Overview

MARK1 (CodeVibs) is a real-time community platform built exclusively for students. It offers a seamless experience for global chatting, club collaborations, event sharing, and personal dashboards — all powered by Django and WebSockets.

This platform is designed to feel like a digital extension of a college campus:  
📌 Real-time global chat  
📌 Personalized dashboards  
📌 Club & community features  
📌 Noticeboard for events and shows  
📌 Profile management and media uploads  

---

## ⚙️ Tech Stack

| Layer       | Tech Used                            |
|-------------|--------------------------------------|
| Backend     | Django, Django Channels              |
| Database    | PostgreSQL                           |
| Realtime    | WebSockets (Daphne)                  |
| Container   | Docker, Docker Compose               |
| Deployment  |  Render (WIP)                        |
| Static/Media| WhiteNoise, Cloud Storage (Cloudinary|

## ✨ Features

### 👥 User System  
- Signup, login, logout  
- Profile picture and user info editing  
- Superuser admin panel

### 🌐 Global Chat  
- Real-time messaging with WebSocket support  
- Messages broadcasted across the platform instantly

### 🏛️ Clubs & Communities  
- Create, join, and manage clubs  
- Each club has its own dedicated chatroom

### 📢 Noticeboard  
- Public board for posting events, shows, updates  
- Supports media/image uploads  
- Visible to all users in real-time

### 📊 Dashboard  
- Personalized feed and stats  
- View club activities, upcoming events, and more (in progress)
